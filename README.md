# Altium-Embedded-Control-Board

An industrial-grade, high-performance IoT and Telemetry Gateway board designed for robust data acquisition, precise positioning, and long-range communication.

* **MCU:** STM32 Main Controller
* **LoRa:** EBYTE E220-400T30S (Long-range wireless telemetry)
* **Ethernet:** Wiznet W5500 (Hardwired TCP/IP with RJ45)
* **GPS/GNSS:** Quectel L26 (Precise positioning & timing)
* **USB-UART:** FTDI FT232RL (PC interface for debugging/monitoring)
* **Storage:** MicroSD Card Slot (Data logging & offline queuing)
* **Power:** Buck-converter with reverse-polarity & overcurrent protection
